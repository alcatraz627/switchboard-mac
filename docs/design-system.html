Switchboard design system

What Switchboard is built from: the tokens, the primitives every tab reuses, the composites they make, and the behaviour rules that keep one grammar across the menu-bar icon, the hover card and the panel. Every piece names the file it lives in, so this page can be checked against the code.

Principles

  • One surface, one grammar. The icon, the hover card and the panel share navigation, input and status rules. A behaviour learned once works everywhere.
  • Hierarchy is size and weight, not colour. Three text roles carry the structure: title, label, caption.
  • Colour means something or it is not there. Red is broken, orange needs a look, yellow waits on you, green is fine. Tag colours avoid all four.
  • Text wraps. Prose never ends in "…". Names (a device, a repo, a model) keep to one line and lose their middle only when they do not fit.
  • Speed is measured. A claim about a slow or fast surface comes with the timing (--time-tabs, the log's open time).

Tag colours

Sources/Timers.swift · timerColors, tagColorName

Eight macOS system colours for notes and timers, the Reminders set: red, orange, yellow, green, teal, blue, purple, pink. They are shown as colour only, never named; names saved under an earlier set (indigo, mint, brown, gray) map to purple, green, orange and blue.

Behaviour rules

RuleWhere it is enforced
Enter does the field's main action; Escape only lets go of the keyboard, never closes or deletes.Inputs.swift EditorText, every onExitCommand
Opening Notes or Timers puts the cursor in the new item's field, unless something is being edited.InputRules.focusNewInput, EditingState
Scroll over a thing adjusts that thing: a tab row steps tabs, a slider steps its level, content scrolls content.ScrollSteps.swift ScrollStepper, ScrollTargets
Number keys pick a hover page only when no text field has the keyboard.QuickCycle.page(forKey:)
Every problem is an error or a warning; only errors turn the icon red or pull the panel to a tab.Problem, ProblemLevel, attention(problems:)
Names keep to one line and lose their middle only when they do not fit; prose wraps.nameFit, SystemRow.labelIsName
Read-only detail text is selectable and copies with ⌘C.selectable in SystemRowView
