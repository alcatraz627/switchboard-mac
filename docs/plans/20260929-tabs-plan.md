# Switchboard tabs, reorganised

Owner asks, 2026-09-29: approvals get their own tab with a count badge, shown
only when something waits; rules and hooks share a tab; mistakes and proposals
share a tab; skills, parked skills, knowledge and scripts share a tab; local
models, dev servers and launchd processes share a tab; plugins and MCPs get a
tab with a global/project filter; checkpoints undecided. More tabs are fine when
they make things easy to find. Every list tab gets the Skills tab's machinery:
rows that open to details, a pinned search field, click to copy a path.

## Tabs

| Tab | Sections | What it shows / can do |
|---|---|---|
| **Approvals (N)** | Pushes · Policy asks · Left by ended sessions | Only present while something waits; the tab label carries a round count badge. Each item: Approve (writes the gate's single-use file and wakes the session), Copy the line, Cancel, and details. The Needs-you strip stays beside it until the owner has tried the tab and says to remove it ("first we prove the new feature works fine and I like it before decommisioning the older one"). |
| **Agents** | Policies · Context | The agent policy store (unchanged), plus the claude.ai connectors and browser tools switches, which move here from Machine because they shape what agents load. |
| **Usage** | Claude · Codex · What acts on these numbers | Unchanged. |
| **Rules & Hooks** | Rules · Gates · Hook scripts · Permission prompts | Rules: each rule's brief, always-loaded or scoped, triggers, path. Gates: every hook gate on / muted / snoozed with Re-arm and Lift (moves from Machine > Guards). Hook scripts: every script in scripts/hooks with its event and whether settings.json wires it, so unwired and orphaned hooks show. Permission prompts: moves from Machine. |
| **Ledger** | Mistakes · Proposals · Checkpoints | Mistakes: atone slugs by recurrence, severity, precheck, RCA path. Proposals: the backlog by state (open, promoted, dropped), effort, links. Checkpoints (optional, owner undecided): the last 20 with a copyable `/catchup` line. |
| **Library** | Skills · Parked skills · Knowledge · Personas · Scripts | Today's Skills tab, grown: live skills, parked skills beside them, features/conventions/global memory docs with their brief and staleness, personas, and scripts by their header. One search across every section. |
| **Runtime** | Services · Dev servers · Local models · Schedules | Everything that runs: kanban, session hub, ipc broker, warden (from Machine > Services); the port ledger with Kill/Disable; Ollama, warm companion, mem-guard; launchd jobs with Start/Stop/Enable/Disable. All move from Machine. |
| **Plugins & MCP** | Plugins · MCP servers | Installed plugins and configured MCP servers, what each adds, enabled or not, with a Global / This project filter. |
| **Machine** | Session · Drives · Repos | What is left for this Mac itself: Keep Awake, Board sync, Wake a device; attached drives; git repos needing attention. |
| **Controls** | Sound · Display · Wi-Fi · Bluetooth | Unchanged. |
| **Home** | Lights | Unchanged (plugs deferred). |
| **Remote** | Console · Hosts | Unchanged. |

Twelve tabs at four per row is three rows; Approvals appears and disappears as
the first tab, so the grid shifts by one while something waits.

## What moves out of existing tabs

| From | Section | To | Why |
|---|---|---|---|
| Machine | Guards (Gates, Permission prompts) | Rules & Hooks | They are hook and settings state, not this Mac's hardware |
| Machine | Context | Agents | They decide what every agent session loads |
| Machine | Services, Dev servers, Local models, Schedules | Runtime | Processes that run, with start/stop controls |
| Needs-you strip | all | Approvals tab | Owner ask; the strip took space on every tab |
| Skills | (whole tab) | Library > Skills | Library holds every browsable doc set |
