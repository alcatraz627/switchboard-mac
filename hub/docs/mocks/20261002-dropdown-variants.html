Dropdown variants

What the dropdown is for

The menu under the menu-bar icon answers one question at a glance: which session needs me. Six layouts follow, all drawn from the same sample data so only the layout differs.

How a session gets its state

Needs you

  • Waiting for the owner's reply.

Working

  • Actively running: thinking, a tool, or writing.

Idle

  • The agent is still open in a terminal and its process is alive, but it is doing nothing.
  • Always shown. Never hidden, never confused with ended.

Liveness is checked by process id on every scan, so there are no false negatives. A closed terminal disappears on the next scan, about 2 s later, so a false "idle" does not linger. Ended sessions live only under Recent.

Colour meaning: yellow waiting, green working, grey idle, red broken or context low.
